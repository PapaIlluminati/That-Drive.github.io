# That-Drive.github.io
A repository related to professional driving.

The file TPD53WorksheetV3.1.html is a web page worksheet for predicting/estimating the weight of 53 ft tandem wheel turnpike double configurations that use an A convertor.
It follows Saskatchewan LCV rules that should be in line with Western Canada MOU.
It displays warnings in red for overweights and bad configurations.
It has a table that can be used to compare the calculated bridge weight to the allowed weight based on your measured interaxle spread to determine if you are legal.
The combination should always be reweighed once built to determine the actual weight of the combination.
